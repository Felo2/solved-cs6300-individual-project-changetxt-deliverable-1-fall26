<h2 style="margin-left: -.25pt;" class="akch-demoted-h1">Specification</h2>
<p class="MsoNormal" style="margin: 0cm 3.5pt 17.35pt -.25pt;">changetxt is a command-line utility written in Java with the following specification:

<p class="MsoNormal" style="line-height: 107%; margin: 0cm 0cm 5.2pt -.25pt;"><b style="mso-bidi-font-weight: normal;"><span style="font-size: 18.0pt; mso-bidi-font-size: 12.0pt; line-height: 107%;">Summary </span></b>

<p class="MsoNormal" style="margin: 0cm 3.5pt 17.15pt -.25pt;">changetxt allows for simple text manipulation of the contents of a file.

<p class="MsoNormal" style="line-height: 107%; margin: 0cm 0cm 5.2pt -.25pt;"><b style="mso-bidi-font-weight: normal;"><span style="font-size: 18.0pt; mso-bidi-font-size: 12.0pt; line-height: 107%;">Syntax </span></b>

<h2 style="margin-left: -.25pt;">Description</h2>
<p class="MsoNormal" style="margin: 0cm 3.5pt 17.25pt -.25pt;">The program changetxt performs basic text transformation on the lines of text from an input file. It is invoked as a command-line tool using the <u style="text-underline: #1155CC;"><span style="color: #1155cc;">syntax described above</span></u>, after compilation. The program writes the transformed text to the standard output and errors or usage messages to the standard error without modifying the input file. The FILE parameter is required and must be the last parameter as shown above. The <b style="mso-bidi-font-weight: normal;">only options allowed in the program</b>, which are optional, delimited by the left [ and right ] brackets, may be provided in any order and are described as follows:

<p class="MsoNormal" style="text-indent: 0cm; line-height: 105%; tab-stops: center 208.5pt; margin: 0cm 0cm 9.6pt 0cm;"><b style="mso-bidi-font-weight: normal;">Option</b> <span style="mso-tab-count: 1;">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span><b style="mso-bidi-font-weight: normal;">Description</b>

<p class="MsoNormal" style="line-height: 103%; margin: 0cm 0cm 15.8pt 5.0pt;"><span style="font-family: Consolas; mso-fareast-font-family: Consolas; mso-bidi-font-family: Consolas;">-n &lt;width&gt;</span> <span style="mso-tab-count: 1;">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span><b style="mso-bidi-font-weight: normal;">Add Line Numbers</b>: <span style="font-family: 'Arial',sans-serif; mso-fareast-font-family: Arial;">Add a line number with numeric </span><span style="font-family: Consolas; mso-fareast-font-family: Consolas; mso-bidi-font-family: Consolas;">padding</span><span style="font-family: 'Arial',sans-serif; mso-fareast-font-family: Arial;"> followed by a <b style="mso-bidi-font-weight: normal;">single space</b> to the beginning of each line, where </span><span style="font-family: Consolas; mso-fareast-font-family: Consolas; mso-bidi-font-family: Consolas;">padding </span><span style="font-family: 'Arial',sans-serif; mso-fareast-font-family: Arial;">is an integer in the inclusive range of 1 to 9 specifying the minimum padding of the line number field. If the number of digits in the line number is less than the specified padding, zeros are left padded until the minimum padding is reached. If the number of digits in the line number is greater than the specified padding, the line number is <b style="mso-bidi-font-weight: normal;">never truncated</b>. Line numbering should start at 1.</span> <b style="mso-bidi-font-weight: normal;">This option is mutually exclusive with –t.</b>

<p class="MsoNormal" style="margin: 0cm 3.5pt .2pt 176.1pt;"><b style="mso-bidi-font-weight: normal;">Truncate Lines:</b> Truncate each line to at most

<p class="MsoNormal" style="text-align: justify; text-justify: inter-ideograph; line-height: 105%; margin: 0cm 0cm 15.5pt 176.1pt;"><b style="mso-bidi-font-weight: normal;">option is mutually exclusive with –n.</b>

This option is </span>

<p class="MsoNormal" style="line-height: 103%; margin: 0cm 0cm 9.05pt 175.35pt;"><span style="font-family: 'Arial',sans-serif; mso-fareast-font-family: Arial;">used with the </span><span style="font-family: Consolas; mso-fareast-font-family: Consolas; mso-bidi-font-family: Consolas;">-f </span><span style="font-family: 'Arial',sans-serif; mso-fareast-font-family: Arial;">flag <b style="mso-bidi-font-weight: normal;">only</b>. </span>The search is <b style="mso-bidi-font-weight: normal;">casesensitive.</b>

The search is <b style="mso-bidi-font-weight: normal;">case-sensitive.</b> The &lt;style&gt; parameter can only be one of three case-sensitive string values: <b style="mso-bidi-font-weight: normal;">“bold”, “italic”, or “code”</b>.<b style="mso-bidi-font-weight: normal;"> </b>

<h3 style="margin-left: -.25pt;">Order of execution</h3>
<p class="MsoNormal" style="margin: 0cm 3.5pt 4.75pt -.25pt;">The last command-line parameter provided is always treated as the filename, as shown in the <u style="text-underline: #1155CC;"><span style="color: #1155cc;">syntax section</span></u>, while <span style="font-family: Consolas; mso-fareast-font-family: Consolas; mso-bidi-font-family: Consolas;">OPTIONS</span> flags can appear in any order and parsed as they appear from left to right. This means that the following two commands are equivalent when executed on the command line:

<p class="MsoNormal" style="line-height: 107%; margin: 0cm 0cm 9.15pt 5.25pt;">Example 1 <span style="font-family: Consolas; mso-fareast-font-family: Consolas; mso-bidi-font-family: Consolas;">changetxt</span> <span style="font-family: Consolas; mso-fareast-font-family: Consolas; mso-bidi-font-family: Consolas;">-n 4 –t 5 input.txt </span>

<p class="MsoNormal" style="line-height: 107%; margin: 0cm 0cm 10.4pt 5.25pt;">Example 2 <span style="font-family: Consolas; mso-fareast-font-family: Consolas; mso-bidi-font-family: Consolas;">changetxt</span> <span style="font-family: Consolas; mso-fareast-font-family: Consolas; mso-bidi-font-family: Consolas;">-t 5 –n 4 input.txt </span>

<p class="MsoNormal" style="margin: 0cm 3.5pt 9.35pt -.25pt;">In the above examples, (Example 1) parses <span style="font-family: Consolas; mso-fareast-font-family: Consolas; mso-bidi-font-family: Consolas;">-n</span> first, then <span style="font-family: Consolas; mso-fareast-font-family: Consolas; mso-bidi-font-family: Consolas;">-t</span>, and finally <span style="font-family: Consolas; mso-fareast-font-family: Consolas; mso-bidi-font-family: Consolas;">input.txt</span> while (Example 2) parses <span style="font-family: Consolas; mso-fareast-font-family: Consolas; mso-bidi-font-family: Consolas;">-t</span> first, then <span style="font-family: Consolas; mso-fareast-font-family: Consolas; mso-bidi-font-family: Consolas;">-n</span>, and finally input.txt. <p class="MsoNormal" style="text-indent: 18.05pt; margin: 0cm 7.3pt 5.65pt -.75pt;"><span style="font-family: 'Segoe UI Symbol',sans-serif; mso-fareast-font-family: 'Segoe UI Symbol'; mso-bidi-font-family: 'Segoe UI Symbol';"></span> An empty input file shall produce an empty output. The <u style="text-underline: #1155CC;"><span style="color: #1155cc;">Examples section</span></u> below shows a case of an empty input file. <b style="mso-bidi-font-weight: normal;"><i style="mso-bidi-font-style: normal;">Java </i></b>

Additionally, you may assume that your application will be called with valid <span style="font-family: Consolas; mso-fareast-font-family: Consolas; mso-bidi-font-family: Consolas;">String[]</span> args.

<h2 style="margin-left: -.25pt;">Part I</h2>
<p class="MsoNormal" style="margin: 0cm 3.5pt 11.2pt -.25pt;">Your task for this deliverable is to generate 50 to 90 (inclusive) test frames for the changetxt utility using the category-partition method presented in lesson P4L2. Make sure to watch the lesson and demo before getting started.

<p class="MsoNormal" style="margin: 0cm 3.5pt 11.45pt -.25pt;">When defining your test specifications, your goal is to suitably cover the domain of the application under test, including relevant erroneous input and input combinations. For example, if you were testing a calculator, you may want to cover the case of division by zero.

<p class="MsoNormal" style="margin: 0cm 3.5pt 11.5pt -.25pt;"><b style="mso-bidi-font-weight: normal;">Do not manually generate combinations of inputs as single choices</b>.
